# Metis 26.7.27 · 忙什么，一眼看懂

这一版重新设计了 Metis 的智能体运行状态。

当 Metis 正在理解任务、查找资料、执行工具或整理回答时，当前 AI 回复中会显示对应的 Thinking Orb 和简短说明。运行过程不再挤在输入框上方，也不再只剩一个含义模糊的旋转图标。

## Thinking Orbs

- **由真实事件驱动。** 根据模型请求、搜索、工具执行、上下文整理和流式回答切换状态，不随机播放动画。
- **跟随当前 AI 回复。** 运行状态与本轮工具调用和输出保持在同一条时间线中，不占用 Composer 上方空间。
- **提示更加直接。** 使用“正在理解你的要求”“正在检索并筛选相关资料”“正在组织回答”等面向任务的文案。
- **保留执行细节。** 轮次、步骤、耗时和可跳转工具仍然可见，不把可验证信息藏在动画后面。
- **节奏更舒缓。** 20px 内联动画使用 Thinking Orbs 原始 64px 演示的运动节奏，同时保留适合消息流的紧凑尺寸。
- **失败状态更稳定。** 准备、重试和重连统一使用 Orb；真正失败时直接显示错误标志，不再闪烁心电图图标。

排队消息和后台子智能体仍保留在输入区附近。它们属于跨回复状态，与当前 AI 回复正在做什么是两层不同的信息。

## 安装

- 支持 Windows 10 / 11 64 位。
- 下载并运行 `Metis-Setup-26.7.27.exe`。
- 升级安装会保留现有会话与本地模型配置。
- 当前安装包尚未代码签名，Windows SmartScreen 可能显示提示。
- 安装包不包含任何本地 API Key；首次启动后请在设置中配置模型服务。
